# Submissions

One YAML file per verification application, at `<github_username>/<module_code>.yaml`.
These files are the public verification record — see [docs/PROCESS.md](../docs/PROCESS.md).

Generated by `verification-layer submit` / `decide` (see
[src/verification_layer/cli.py](../src/verification_layer/cli.py)) — don't hand-edit
except to fix a typo; decisions should go through `decide` so `decided_at` and
`status` stay consistent with the recorded score.
